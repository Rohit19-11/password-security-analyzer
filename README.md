# 🔐 Password Security Analyzer

A web-based cybersecurity tool that checks how strong your password is in real time.

---

## 🚀 Features
- Password strength checker
- Real-time feedback
- Security scoring system
- Simple UI

---

## 🛠 Tech Used
- React
- TypeScript
- Vite

---

## ▶️ How to Run

### 1. Install dependencies
npm install

### 2. Run project
npm run dev
